# The Ledger — UX Mockup

A standalone, simulated-data prototype of The Ledger spa/wellness management app.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save. GitHub will publish the app.

No login, database, API, Cloudflare Worker, or build system is required.

## Demo data

All appointments, clients, products, protocols, and notes are simulated. Buttons that save/start actions show demo behavior only.

## Included UX

- Dashboard/home
- Today's schedule
- Appointment details and treatment workflow
- Structured SOAP note
- Allergy lookup
- Treatment protocols
- Product/supply inventory
- Mobile bottom navigation
- Responsive desktop/tablet/mobile layout
